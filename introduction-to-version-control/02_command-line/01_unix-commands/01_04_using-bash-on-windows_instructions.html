If you are using a macOS or Linux machine, your computer natively understands Unix commands. However, if you are using a Windows machine, you need to take a few extra steps before you can follow along with the upcoming demonstrations.

The Problem with CMD and PowerShell

Windows comes with two default command-line tools: Command Prompt (CMD) and PowerShell . These tools use a different language than Unix.

If you try to type Unix commands like ls -la, pwd, or chmod into standard Windows CMD, you will receive a frustrating "Command Not Found" error.

The Solution: Git Bash

To run Unix commands on a Windows machine, you must install a "terminal emulator." For software developers, the absolute industry standard is a free tool called Git Bash .

Git Bash provides you with a Unix-style terminal on your Windows machine, allowing you to use all the commands taught in this course.

How to Install and Open Git Bash

If you do not already have Git Bash installed, please follow these steps:

  1. Navigate to the official Git for Windows website: https://gitforwindows.org/

  2. Click the Download button.

  3. Open the downloaded installer file.

  4. Click Next through the installation prompts. (The default settings are perfectly fine for this course, so you do not need to change any checkboxes).

  5. Once the installation is complete, click your Windows Start Menu and search for Git Bash .

  6. Open the Git Bash application.

You should now see a black terminal window with a blinking cursor. You will use this specific Git Bash window for all command-line and version control exercises in this course.

Whenever the upcoming videos or labs ask you to "open your terminal," please remember to open Git Bash , not Windows Command Prompt.

Git works on all operating system platforms, including Windows, Mac, and Linux. The majority of developers use Git via the command line because its syntax is standard and easy to follow. Git also integrates seamlessly into code editors and other Graphical User Interfaces (GUIs).

Follow the instructions below for your specific operating system to get Git set up on your computer.

For Windows Users

  1. Go to the official Git for Windows website: https://gitforwindows.org/

  2. Click the Download button for the latest version.

  3. Once the download is complete, open the installation file.

  4. Navigating the Installer: The Git installation wizard has many screens with complex configuration options. You can safely leave all the default options selected. Simply keep clicking Next until the installation finishes.

  5. After installation, open your Windows Start menu, search for Git Bash , and open the application. (Note: For this course, please use Git Bash rather than the standard Windows Command Prompt).

For Mac Users

In many cases, Git is already installed on your Mac by default!

  1. Open your Terminal application (you can find this by searching "Terminal" in Spotlight).

  2. Type git --version and press Enter.

  3. If Git is installed, it will show you the version number.

  4. If Git is not installed, your Mac will automatically prompt you to install the "Command Line Developer Tools." Click Install and follow the prompts. Once finished, Git will be ready to use.

Verify Your Installation

To confirm that Git is successfully installed on your computer, open your terminal (Git Bash for Windows, or Terminal for Mac) and type the following command exactly as it appears:

git --version

Press the Enter key. You should see an output similar to this: git version 2.39.1 (Note: Your specific version number may be slightly different, and that is perfectly fine!) 

$ git version
git version 2.39.1

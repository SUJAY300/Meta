Git works on all operating system platforms, including Windows, Mac, and Linux. The majority of developers will use Git via the command line because its syntax is standard and easy to follow. Git also integrates seamlessly into code editors and other Graphical User Interfaces (GUIs).

Step 1: Check if Git is already installed

Macs often have Git installed by default. Before downloading any new software, you should check if it is already on your computer.

Open your Terminal application (you can find it by searching "Terminal" in Spotlight) and type the following command exactly as it appears:

git --version

Press Enter .

  • If the terminal returns a version number (e.g., git version 2.30.1 (Apple Git-130) , Git is already installed! You do not need to do anything else and can skip to the Configuration step at the bottom of this page.

  • If the terminal returns "command not found" (or prompts you to install developer tools), proceed to Step 2.

Step 2: Install Git (Choose one method)

If you need to install Git, there are a few ways to do it on a Mac. We recommend using Method A , as it is the fastest and easiest.

Method A: Install via Xcode Command Line Tools (Recommended) You do not need to download the massive, full Xcode application to get Git. Apple provides a lightweight package specifically for terminal users.

  1. In your terminal, type the following command and press Enter: xcode-select --install

  2. A pop-up window will appear asking if you want to install the command line developer tools. Click Install .

  3. Once the installation finishes, run the git --version command again to verify it was successful.

Method B: Install via Homebrew (Alternative) Homebrew is a highly popular package manager for Macs. It makes it incredibly simple to install new software via the terminal.

  1. First, you need to install Homebrew. Go to https://brew.sh/ , copy the install command provided on their homepage, and run it in your terminal.

  2. Once Homebrew is fully installed, type the following command to install Git: brew install git

  3. Once installed, run the git --version command to verify the installation is complete.

(Note: You can also get Git by downloading the full Xcode application from the Mac App Store. However, because Xcode is a very large application designed for iOS development, it uses a lot of memory space. Methods A and B are much better alternatives for general web developers).

Step 3: Configure Your Git Account

Once Git is successfully installed on your Mac, you need to configure your user information. Git attaches this information to every code save (commit) you make.

Run the following two commands in your terminal, replacing the placeholder text inside the quotes with your actual name and email address:

git config --global user.name "Your Name"

git config --global user.email "your.email@example.com"

You are now fully set up and ready to use Git!

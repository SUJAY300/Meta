Course Overview

In this course, you will learn how modern software developers collaborate across the world without conflicting with each other's code. You will explore different version control systems and discover how to establish an effective software development workflow. Next, you will be introduced to essential Linux commands used to navigate your hard drive and create powerful, automated workflows that save time and effort. Finally, you will learn how Git is used in software development projects to manage team files, and you will create your own repository to track code revisions.

After completing this course, you will be able to:

  • Implement version control systems.

  • Navigate your file system and configure settings using the command line.

  • Manage code revisions effectively.

  • Create and use a GitHub repository.

The modules and resources in this course are designed to prepare you for the final exam. Below is an outline of the modules covered in this course:

Module 1: Software Collaboration

In this module, you will learn how version control brings order to large-scale software projects, minimizing the potential for mistakes and bugs. You will examine various version control systems and learn how to design an effective software development workflow.

After completing this module, you will be able to:

  • Describe how modern software teams collaborate on a shared codebase.

  • List different version control systems and methodologies.

  • Illustrate a standard software development workflow.

Module 2: Command Line

In this module, you will learn how to use the command line to execute instructions in Linux. You will be introduced to commonly used commands to navigate, create, rename, and delete files on your hard drive. You will also learn how to use piping and redirection to build powerful workflows that automate your tasks and save you effort.

After completing this module, you will be able to:

  • Describe what the command line is and how it is used.

  • Navigate your hard drive via the command line.

  • Create, rename, and delete files and folders using Unix/Linux commands.

  • Apply pipes and redirection to streamline workflows.

Module 3: Git

This module will help you build a strong conceptual understanding of Git and its role in managing team files during software development. You will learn how to install Git, initialize a local repository, make commits, and push those commits to a remote repository.

After completing this module, you will be able to:

  • Outline core Git principles.

  • Set up and use a GitHub repository.

  • Describe the steps in a standard GitHub workflow.

  • Create branches and merge code from different sources.

  • Explain how code progresses from local development, to version control, and finally to live production.

Module 4: Graded Assessment

In this final module, you will complete the graded assessment. By synthesizing the skills you have gained throughout the course, you will manage a complete project on GitHub. You will also have the opportunity to reflect on the course content and your ongoing learning path.

After completing this module, you will be able to:

  • Review all the key topics covered throughout the course.

  • Apply your newly acquired skills to successfully complete a graded project.

Practical Exercises

We highly encourage you to complete the practical exercises provided in this course. Engaging with these exercises will give you hands-on experience and a much deeper, practical understanding of how to apply version control in real-world scenarios.

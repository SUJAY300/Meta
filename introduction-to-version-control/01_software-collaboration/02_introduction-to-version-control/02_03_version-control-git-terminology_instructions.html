As you progress through this course, you will be introduced to a variety of Git commands and industry-standard terminology. To support your learning, this resource will serve as a handy, quick-reference guide. Below, you will find the official Git Cheat Sheet provided by GitHub, which includes essential command-line instructions, a visual guide to the GitHub workflow, and a helpful glossary of key terms. We highly recommend downloading the attached PDF to keep on hand as you complete your practical exercises and build your repositories.

A Note on Modern Git Best Practices: While this official cheat sheet is a fantastic visual reference, the tech industry evolves rapidly. Please keep the following modern updates in mind when reviewing the document:

  • main instead of master: The visual diagram refers to the default branch as master. Modern GitHub repositories now universally use main as the default branch name.

  • git switch instead of git checkout: The cheat sheet lists git checkout to change branches. While this command still works perfectly, modern Git best practice is to use git switch [branch-name] , which was introduced specifically to make branching easier and safer.

  • GitHub Desktop: The download links listed on the side of the PDF are legacy links. To download the modern application, please search online for GitHub Desktop .

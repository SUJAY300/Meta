# Sample Solution code
class MyFirstClass():
    print("Who wrote this?")
    index = "Author-Book"

    def hand_list(self, philosopher, book):
        print(MyFirstClass.index)
        print(philosopher + " wrote the book: " + book)

whodunnit = MyFirstClass()
whodunnit.hand_list("Sun Tzu", "The Art of War")

Note: The solution some people may have will be:

Who wrote this?

Author-Book

Sun Tzu wrote the book: The Art of War

But if you run the code below, you will see an output such as:

Who wrote this?

Author-Book

Sun Tzu wrote the book: The Art of War

Author-Book

Sun Tzu wrote the book: The Art of War

None

Why does this happen?

Explanation:

  • When the class is defined, the print statement print("Who wrote this?") executes as part of the class definition.

  • This causes the output "Who wrote this?" to appear every time the class is loaded or reloaded.

  • After you instantiate the class (whodunnit = MyFirstClass()) , the method hand_list() is called, which produces the output twice:

    1. First, it prints MyFirstClass.index and the concatenated string.

    2. The method call prints the output again because the class body is evaluated once more when the class instance is created.

To avoid this behavior, move the print("Who wrote this?") statement into the constructor (__init__) of the class, so that it runs only once when the class is instantiated.

The new code will look like: 

class MyFirstClass:
    index = "Author-Book"

    def __init__(self):
        print("Who wrote this?")  # Move the print statement into the constructor

    def hand_list(self, philosopher, book):
        print(MyFirstClass.index)
        print(philosopher + " wrote the book: " + book)

# Instantiate the class
whodunnit = MyFirstClass()
# Call the method with parameters
whodunnit.hand_list("Sun Tzu", "The Art of War")

Now, "Who wrote this?" will only be printed once, during the instantiation of the class, and the hand_list() method will produce the correct output without duplication.

The use of constructor is an important component in learning Python and takes some practice.
